## Current position

Dopis is **post-PLAN-004 and pre-implementation**. The accepted planning model contains 18 vertical slices covering the 25-story / 27-acceptance-criterion first-MVP backlog, but it does not authorize implementation, ADRs, technical acceptance criteria, tests, tasks, or execution packets.

The next material step is an Owner decision selecting and authorizing the next bounded technical-planning activity. This roadmap does not select a slice, create implementation authority, or duplicate the detailed vertical-slice model.
